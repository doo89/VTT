1. Vue d'ensemble

Le composant SettingsModal est une modale React de configuration principale de l'application VTTApp. Il utilise Zustand pour la gestion d'état global et propose un système de 6 onglets de navigation horizontale dans une interface responsive avec backdrop blur.

10. Points techniques notables

Upload de fichiers

FileReader.readAsDataURL() convertit les images et sons en base64 data URL. Deux handlers : handleImageUpload (l.127) et handleTimerSoundUpload (l.116).

Drag & Drop

API HTML5 native avec draggable, onDragStart, onDragOver, onDragEnd. Réordonnancement via Array.splice().

Preview live

Composant BadgePreview avec useRef + useEffect pour mise à jour DOM directe des couleurs des badges sur le pion simulé.

Accessibilité

Labels htmlFor liés aux inputs, aria-label sur les boutons d'action, title pour les tooltips natifs.

Architecture CSS

  • Modal : fixed inset-0 bg-black/60 z-[100] backdrop-blur-sm
  • Conteneur : max-w-4xl max-h-[90vh] border border-border
  • Scroll : custom-scrollbar (classe CSS externe)
  • Responsive : md:grid-cols-2, md:grid-cols-3, sm:gap-x-48

Ordre par défaut des panneaux

 'tagDistributor', 'wiki', 'popupCreator', 'actionCreator', 
 'checklist', 'magneticPoints', 'system']
